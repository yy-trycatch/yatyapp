Features

// 核心能力

watermark

時間、日期、地址、經緯度、海拔、天氣、裝置型號、自定義文字和 Logo，每個欄位都可單獨編輯或隱藏。

templates

通用、生活、工作彙報、巡檢、考勤五類浮水印樣式，一鍵切換。

video_overlay

錄影時浮水印實時燒錄進影片畫面，時間隨錄製同步更新。

camera

前後攝像頭、變焦、閃光燈、亮度、定時拍攝，3:4 / 9:16 / 1:1 畫幅，流暢 / 標準 / 高畫質畫質。

collage

工作日報、工作彙報、工作記錄、施工日誌等拼圖模板，最多 9 張圖，匯出圖片或 PDF。

editor

裁剪、旋轉、亮度、對比度、飽和度，以及黑白、復古、鮮豔、冷調、暖調、褪色濾鏡。

Screenshots

// 真機截圖

01 / camera

浮水印拍照

取景時即可預覽浮水印效果。時間、日期、位置、座標、天氣、海拔、裝置型號自動填充，拍下即成片。

  • 定位只讀取當前位置，不在後臺追蹤
02 / video

浮水印錄影

切到錄影模式，同一套浮水印樣式直接用於影片，夜景下同樣清晰可讀。

03 / recording

邊錄邊蓋章

錄製過程中浮水印實時寫入每一幀畫面，錄完的影片不需要後期處理。

04 / editor

圖片編輯

對拍好的照片進行裁剪、旋轉、調色和濾鏡處理，儲存後回到相簿。

05 / collage

工作日報拼圖

選擇模板，填寫今日工作和明日計劃，新增最多 9 張現場照片，一鍵生成日報圖片或 PDF。

  • 模板 / 排版 / 表頭可自由組合
  • 歷史草稿自動儲存在本機
