Features

// 核心能力

watermark

时间、日期、地址、经纬度、海拔、天气、设备型号、自定义文字和 Logo，每个字段都可单独编辑或隐藏。

templates

通用、生活、工作汇报、巡检、考勤五类水印样式，一键切换。

video_overlay

录像时水印实时烧录进视频画面，时间随录制同步更新。

camera

前后摄像头、变焦、闪光灯、亮度、定时拍摄，3:4 / 9:16 / 1:1 画幅，流畅 / 标准 / 高清画质。

collage

工作日报、工作汇报、工作记录、施工日志等拼图模板，最多 9 张图，导出图片或 PDF。

editor

裁剪、旋转、亮度、对比度、饱和度，以及黑白、复古、鲜艳、冷调、暖调、褪色滤镜。

Screenshots

// 真机截图

01 / camera

水印拍照

取景时即可预览水印效果。时间、日期、位置、坐标、天气、海拔、设备型号自动填充，拍下即成片。

  • 定位只读取当前位置，不在后台追踪
02 / video

水印录像

切到录像模式，同一套水印样式直接用于视频，夜景下同样清晰可读。

03 / recording

边录边盖章

录制过程中水印实时写入每一帧画面，录完的视频不需要后期处理。

04 / editor

图片编辑

对拍好的照片进行裁剪、旋转、调色和滤镜处理，保存后回到相册。

05 / collage

工作日报拼图

选择模板，填写今日工作和明日计划，添加最多 9 张现场照片，一键生成日报图片或 PDF。

  • 模板 / 排版 / 表头可自由组合
  • 历史草稿自动保存在本机
