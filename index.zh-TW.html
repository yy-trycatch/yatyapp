// 當前在維護的 2 款 Android 應用

[soundmeter] v1.0.6 · Android 8.0+

分貝檢測 SoundMeter

把手機變成噪音計。實時測量環境分貝，錄製帶分貝資料浮水印的影片，所有記錄可回放、可匯出 Excel。

  • 44.1kHz 取樣，A / C 計權
  • 分貝相機：影片疊加實時 dB 與時間地點
  • 歷史曲線點選跳轉到對應影片時刻
  • 聲控自動錄製，6 種介面語言
介紹 -> 隱私 協議
[timestamp] v1.0 · Android 7.0+

印章相機 TimeStamp

拍照、錄影時自動加蓋時間、地點、天氣、海拔浮水印，適合打卡、巡檢、施工記錄和工作彙報。

  • 通用 / 生活 / 工作 / 巡檢 / 考勤浮水印模板
  • 影片浮水印實時燒錄進畫面
  • 工作日報拼圖，匯出圖片或 PDF
  • 內建圖片編輯：裁剪、旋轉、濾鏡
介紹 -> 隱私 協議

Principles

// 寫在每個 App 裡的幾條規則

local_first()

照片、影片、測量記錄預設只存在你的裝置上，我們沒有用於收集使用者資料的後臺伺服器。

least_privilege()

只在用到功能時申請權限。定位等可選權限拒絕後，核心功能依然可用。

no_signup()

不需要註冊帳號即可使用。只有購買或恢復會員時才需要 Google 登入。

transparent()

隱私條例按實際程式碼逐項列出權限、第三方 SDK 和資料流向。
