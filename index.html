Products

// 当前在维护的 2 款 Android 应用

[soundmeter] v1.0.6 · Android 8.0+

分贝检测 SoundMeter

把手机变成噪音计。实时测量环境分贝，录制带分贝数据水印的视频，所有记录可回放、可导出 Excel。

  • 44.1kHz 采样，A / C 计权
  • 分贝相机：视频叠加实时 dB 与时间地点
  • 历史曲线点击跳转到对应视频时刻
  • 声控自动录制，6 种界面语言

[timestamp] v1.0 · Android 7.0+

印章相机 TimeStamp

拍照、录像时自动加盖时间、地点、天气、海拔水印，适合打卡、巡检、施工记录和工作汇报。

  • 通用 / 生活 / 工作 / 巡检 / 考勤水印模板
  • 视频水印实时烧录进画面
  • 工作日报拼图，导出图片或 PDF
  • 内置图片编辑：裁剪、旋转、滤镜

Principles

// 写在每个 App 里的几条规则

local_first()

照片、视频、测量记录默认只存在你的设备上，我们没有用于收集用户数据的后台服务器。

least_privilege()

只在用到功能时申请权限。定位等可选权限拒绝后，核心功能依然可用。

no_signup()

不需要注册账号即可使用。只有购买或恢复会员时才需要 Google 登录。

transparent()

隐私条例按实际代码逐项列出权限、第三方 SDK 和数据流向。
