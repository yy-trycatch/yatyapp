[soundmeter] v1.0.6 · Android 8.0+

데시벨 측정 Decibel Meter

휴대폰을 소음 측정기로 바꿔 줍니다. 주변 소음을 실시간으로 측정하고, 실시간 dB가 표시된 동영상을 녹화하며, 모든 기록을 다시 재생하고 Excel로 내보낼 수 있습니다.

  • 44.1kHz 샘플링, A / C 주파수 가중
  • dB 카메라: 동영상에 실시간 dB, 시간, 장소 표시
  • 기록 차트를 탭하면 동영상의 해당 시점으로 이동
  • 소리 감지 자동 녹음, 6개 UI 언어

[timestamp] v1.0 · Android 7.0+

TimeStamp Camera

촬영하는 즉시 사진과 동영상에 시간, 위치, 날씨, 고도를 새겨 넣습니다. 출퇴근 체크, 점검, 현장 기록, 업무 보고를 위해 만들었습니다.

  • 일반 / 일상 / 업무 / 점검 / 근태 템플릿
  • 워터마크를 동영상에 실시간으로 합성
  • 일일 보고 콜라주, 이미지 또는 PDF로 내보내기
  • 내장 편집기: 자르기, 회전, 필터

원칙

// 모든 앱에 적용되는 규칙

local_first()

사진, 동영상, 측정 데이터는 기본적으로 사용자의 기기에만 저장됩니다. 사용자 데이터를 수집하는 서버는 운영하지 않습니다.

least_privilege()

권한은 해당 기능에 필요할 때만 요청합니다. 위치 등 선택 권한을 거부해도 핵심 기능은 계속 사용할 수 있습니다.

no_signup()

계정 없이 앱을 사용할 수 있습니다. Google 로그인은 프리미엄을 구매하거나 복원할 때만 필요합니다.

transparent()

개인정보 처리방침에는 권한, 제3자 SDK, 데이터 흐름을 코드에 구현된 그대로 기재합니다.
