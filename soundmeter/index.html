分贝检测
SoundMeter

把手机变成一台随身噪音计。实时测量环境分贝，录制叠加分贝数据的视频，记录可回放、可分享、可导出 Excel。

Features

// 核心能力

realtime_db

44.1kHz 采样，Goertzel 分频段分析，支持 A / C 计权。仪表盘实时显示当前、平均、最大、最小分贝和趋势曲线。

db_camera

录像时把分贝统计、时间、地点、经纬度、天气直接叠加进视频画面，支持前后摄像头和闪光灯。

history

每次测量自动保存。详情页展示分贝曲线，点击曲线上的点即可跳到视频对应时刻。

export

一键打包 Excel（汇总 + 逐点数据）、视频和音频，通过系统分享发送。

voice_trigger

声控录制：环境声音达到设定阈值（默认 70dB，可在 40-140dB 调节）时自动开始录制 3 分钟。

i18n

支持简体中文、繁体中文、English、日本語、한국어、Tiếng Việt。

01 / splash

启动即测

首次启动展示隐私说明，同意后进入主界面，无需注册账号。

02 / noise_check

实时噪音检测

仪表盘显示当前分贝，下方同步显示平均值、最大值、最小值和实时曲线。

  • A 计权：贴近人耳感知

03 / db_camera

分贝相机

边录像边测量。分贝数值、时长、时间、地点和天气直接烧录到视频画面，回看和分享时一目了然。

  • 定位为可选权限，拒绝后照常录制
04 / history_list

历史记录

所有测量记录按时间排列，显示时长和最大、平均、最小分贝，数据保存在本机。

曲线与视频联动

详情页展示完整分贝曲线和视频回放。点击曲线任意位置，视频跳到对应时刻。
