SoundMeter

เครื่องวัดระดับเสียง (เครื่องวัดเสียง) ในกระเป๋าของคุณ วัดเสียงรบกวนรอบตัวแบบเรียลไทม์ บันทึกวิดีโอพร้อมซ้อนข้อมูลค่าเดซิเบล แล้วเปิดดูซ้ำ แชร์ หรือส่งออกทุกบันทึกเป็นไฟล์ Excel

ฟีเจอร์

// ความสามารถหลัก

realtime_db

สุ่มสัญญาณที่ 44.1kHz พร้อมการวิเคราะห์ย่านความถี่ด้วยอัลกอริทึม Goertzel และการถ่วงน้ำหนักแบบ A / C หน้าปัดแสดงค่าเดซิเบลปัจจุบัน ค่าเฉลี่ย ค่าสูงสุด และค่าต่ำสุด พร้อมเส้นแนวโน้มแบบเรียลไทม์

db_camera

ฝังสถิติค่าเดซิเบล เวลา ที่อยู่ พิกัด และสภาพอากาศลงในวิดีโอขณะบันทึก รองรับกล้องหน้า กล้องหลัง และแฟลช

history

ทุกการวัดจะถูกบันทึกไว้โดยอัตโนมัติ หน้ารายละเอียดแสดงกราฟเส้นค่าเดซิเบล แตะจุดใดก็ได้เพื่อข้ามไปยังช่วงเวลานั้นในวิดีโอ

export

รวมไฟล์ Excel (สรุปผลและข้อมูลรายจุด) วิดีโอ และไฟล์เสียงไว้เป็นชุดเดียว แล้วส่งผ่านเมนูแชร์ของระบบ

voice_trigger

บันทึกเมื่อตรวจพบเสียง: เมื่อระดับเสียงถึงเกณฑ์ที่คุณกำหนด (ค่าเริ่มต้น 70dB ปรับได้ในช่วง 40-140dB) ระบบจะเริ่มบันทึกนาน 3 นาทีโดยอัตโนมัติ

i18n

จีนตัวย่อ จีนตัวเต็ม อังกฤษ ญี่ปุ่น เกาหลี และเวียดนาม

ภาพหน้าจอ

// ถ่ายจากเครื่องจริง

01 / splash

เปิดแล้ววัดได้ทันที

เมื่อเปิดแอปครั้งแรกจะแสดงประกาศเกี่ยวกับความเป็นส่วนตัว หลังจากคุณยอมรับ ระบบจะพาเข้าสู่หน้าเครื่องวัดโดยตรง ไม่ต้องมีบัญชี

02 / noise_check

ตรวจวัดเสียงรบกวนแบบเรียลไทม์

หน้าปัดแสดงระดับเสียงปัจจุบัน ด้านล่างแสดงค่าเฉลี่ย ค่าสูงสุด ค่าต่ำสุด และกราฟเส้นแบบเรียลไทม์

  • การถ่วงน้ำหนักแบบ A: ใกล้เคียงกับการได้ยินของมนุษย์
  • การถ่วงน้ำหนักแบบ C: คงความถี่ต่ำไว้มากกว่า
03 / db_camera

กล้องวัดเดซิเบล

วัดเสียงไปพร้อมกับการถ่ายวิดีโอ ค่าเดซิเบล ระยะเวลา เวลา สถานที่ และสภาพอากาศจะถูกฝังลงในวิดีโอ ทำให้เห็นหลักฐานได้ทั้งเมื่อเปิดดูซ้ำและเมื่อแชร์

  • ตำแหน่งที่ตั้งเป็นทางเลือก ไม่ให้สิทธิ์ก็ยังบันทึกวิดีโอได้
04 / history_list

ประวัติการวัด

แสดงบันทึกทั้งหมดเรียงตามเวลา พร้อมระยะเวลาและค่าเดซิเบลสูงสุด / เฉลี่ย / ต่ำสุด ข้อมูลจัดเก็บอยู่บนเครื่องของคุณ

05 / history_detail

กราฟเชื่อมโยงกับวิดีโอ

หน้ารายละเอียดแสดงกราฟค่าเดซิเบลทั้งหมดพร้อมการเล่นวิดีโอ แตะตำแหน่งใดบนกราฟก็ได้เพื่อเลื่อนวิดีโอไปยังช่วงเวลานั้น

  • แชร์ไฟล์ Excel + วิดีโอ + เสียง รวมเป็นชุดเดียว
06 / me

ของฉัน

ลงชื่อเข้าใช้ Google ศูนย์สมาชิก โฆษณาแบบมีรางวัลเพื่อรับโควตาบันทึกเพิ่ม เกณฑ์เสียงสำหรับการบันทึกอัตโนมัติ รวมถึงนโยบายความเป็นส่วนตัวและข้อกำหนด
