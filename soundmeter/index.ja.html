デシベル測定 Decibel Meter
SoundMeter

ポケットに入る騒音計です。周囲の騒音をリアルタイムで測定し、dB データを重ねた動画を録画して、すべての記録を再生・共有したり Excel に書き出したりできます。

機能

// 主な機能

realtime_db

44.1kHz でサンプリングし、Goertzel 法による帯域分析と A / C 特性の重み付けを行います。メーターには現在値・平均・最大・最小の dB と、リアルタイムの推移グラフを表示します。

db_camera

録画中に dB の統計値・時刻・住所・座標・天気を動画へ焼き込みます。前面／背面カメラとフラッシュに対応しています。

history

測定はすべて自動で保存されます。詳細画面では dB の推移グラフを表示し、グラフ上の任意の点をタップするとその瞬間の動画へ移動します。

export

Excel シート（サマリー＋各測定点のデータ）、動画、音声をまとめて、システムの共有シートから送信できます。

voice_trigger

音声感知録画：音量がしきい値（既定 70dB、40〜140dB で調整可能）に達すると、3 分間の録画が自動的に始まります。

i18n

簡体字中国語、繁体字中国語、英語、日本語、韓国語、ベトナム語に対応しています。

スクリーンショット

// 実機で撮影

01 / splash

開いてすぐ測定

初回起動時にプライバシーに関する説明を表示します。同意するとそのまま測定画面へ進みます。アカウントは不要です。

02 / noise_check

リアルタイムの騒音チェック

メーターに現在の音量を表示し、その下に平均・最大・最小とリアルタイムの推移グラフを表示します。

  • A 特性：人の聴感に近い測定
  • C 特性：低音域をより多く残した測定
03 / db_camera

dB カメラ

撮影しながら測定します。dB 値、経過時間、時刻、場所、天気が動画へ焼き込まれるため、再生時や共有時にもそのまま確認できます。

  • 位置情報は任意です。許可しなくても録画できます
04 / history_list

履歴

すべての記録を時系列で一覧表示し、測定時間と最大 / 平均 / 最小の dB を表示します。データは端末内に保存されます。

05 / history_detail

グラフと動画が連動

詳細画面では dB の推移グラフ全体と動画の再生を表示します。グラフのどこをタップしても、動画がその瞬間まで移動します。

  • Excel ＋ 動画 ＋ 音声をひとつにまとめて共有
06 / me

マイページ

Google ログイン、会員センター、リワード広告による記録枠の追加、音声感知のしきい値設定、プライバシーポリシーと利用規約を用意しています。
