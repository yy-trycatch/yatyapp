分貝檢測
SoundMeter

把手機變成一臺隨身噪音計。實時測量環境分貝，錄製疊加分貝資料的影片，記錄可回放、可分享、可匯出 Excel。

Features

// 核心能力

realtime_db

44.1kHz 取樣，Goertzel 分頻段分析，支援 A / C 計權。儀表盤實時顯示當前、平均、最大、最小分貝和趨勢曲線。

db_camera

錄影時把分貝統計、時間、地點、經緯度、天氣直接疊加進影片畫面，支援前後攝像頭和閃光燈。

history

每次測量自動儲存。詳情頁展示分貝曲線，點選曲線上的點即可跳到影片對應時刻。

export

一鍵打包 Excel（彙總 + 逐點資料）、影片和音訊，透過系統分享傳送。

voice_trigger

聲控錄製：環境聲音達到設定閾值（預設 70dB，可在 40-140dB 調節）時自動開始錄製 3 分鐘。

i18n

支援簡體中文、繁體中文、English、日本語、한국어、Tiếng Việt。

Screenshots

// 真機截圖

01 / splash

啟動即測

首次啟動展示隱私說明，同意後進入主介面，無需註冊帳號。

02 / noise_check

實時噪音檢測

儀表盤顯示當前分貝，下方同步顯示平均值、最大值、最小值和實時曲線。

  • A 計權：貼近人耳感知
  • C 計權：保留更多低頻
03 / db_camera

分貝相機

邊錄影邊測量。分貝數值、時長、時間、地點和天氣直接燒錄到影片畫面，回看和分享時一目瞭然。

  • 定位為可選權限，拒絕後照常錄製
04 / history_list

歷史記錄

所有測量記錄按時間排列，顯示時長和最大、平均、最小分貝，資料儲存在本機。

05 / history_detail

曲線與影片聯動

詳情頁展示完整分貝曲線和影片回放。點選曲線任意位置，影片跳到對應時刻。

  • 打包分享 Excel + 影片 + 音訊
